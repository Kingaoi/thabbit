# ملفات الآيات والملاحة

حزمة مختصرة مستقلة تحتوي على الآيات ومعلومات الصفحة والتقسيم القرآني.

- `verses.jsonl`: كل آية مع النص والمعلومات الملاحية.
- `ayah_navigation.jsonl`: المعرفات وأرقام الأجزاء والمنازل والصفحات والأحزاب والأرباع والركوع والسجدات فقط.
- `pages.json`: الآيات مجمعة حسب رقم الصفحة.
- `surahs.json`: معلومات السور.

مفتاح الربط: `id` بصيغة `chapter:verse`. عدد الآيات: 6236.
